Clique
=====
The o.g. click-casting addon
---
Additions:
* SuperWoW support to avoid target switches.
* Luna support
* Fixed clique button for twow druid spellbooks
* Blizzard unit frame click-casting can be disabled with `/clique blizz` (`/reload` required)
* Mouse wheel up/down bindings can be set by scrolling over a spell in the spellbook. They require a GUID-capable client (SuperWoW, ClassicAPI.dll, Puppeteer, etc.) to cast; otherwise the camera zooms normally.

___
* Modified for Weird Vibes of Turtle WoW
